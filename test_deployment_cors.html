🧪 Workflow Deployment CORS Test

Test the Django-based CORS implementation for deployment endpoints

📋 Setup Instructions:

  1. Add allowed origin in Deploy page:
    • Go to your project's "Deploy" section
    • Add origin: http://localhost:5500
    • Set rate limit (e.g., 10 requests/minute)
    • Save the deployment configuration
  2. Restart Docker containers: 
    docker compose restart nginx backend
  3. Serve this HTML file:
    • Using Python: python -m http.server 5500
    • Or using VS Code Live Server on port 5500
  4. Enter your project ID below and test!
